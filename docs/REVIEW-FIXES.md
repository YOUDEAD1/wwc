أضيف محرر المنتجات بالأزرار: قائمة منتجات بأسمائها وإيموجياتها ثم أقسام التعديلات. جميع مسارات أزرار الأدمن السابقة الـ287 باقية، وجميع الدوال والكلاسات الـ929 في الحزمة السابقة محفوظة. أضيفت 10 اختبارات لاختيار المنتج وحفظه والرجوع والترقيم والإخفاء والصلاحيات والمرفقات وإيموجيات البريميوم، بما فيها اختبار عبر كامل وسائط البوت. إجمالي الاختبارات 57.

لا يتصل أي اختبار بقاعدة متجر حقيقية أو API دفع حقيقي. وظائف البريد والمساعد وبعض واجهات reseller التي كانت معطلة أصلًا بطلب صاحب المشروع ما زالت على وضعها الأصلي. فحص الحفاظ على الدوال موجود في `tests/preservation.mjs` ويعمل عند وجود سجل Git المرجعي، لذلك لا يُشغَّل ضمن اختبارات ZIP الذي لا يحتوي `.git`.
