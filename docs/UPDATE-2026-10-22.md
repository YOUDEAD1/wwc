# تحديث WWC — 22 أكتوبر 2026

هذه الحزمة خاصة بمستودع `YOUDEAD1/wwc` الذي يعمل بـ Node.js وTypeScript وSupabase. لا تستبدل بها ملف Python الخاص ببوت LARA STOCK القديم. هذا المستودع لا يتضمن واجهة موقع أو Mini App.

## تثبيت التحديث على متجر قائم

1. احتفظ بنسخة من ملفات التشغيل وإعداداتك الحالية ونسخة احتياطية من قاعدة البيانات.
2. من SQL Editor في مشروع Supabase الخاص بالبوت، شغّل **فقط** `supabase/migrations/0044_secure_checkout_and_runtime.sql`. كرر ذلك لقواعد المتاجر المستأجرة التي ستعمل بهذا الإصدار.
3. لا تعِد تشغيل تاريخ migrations القديم على متجر قائم. بعض الملفات القديمة تتضمن backfill لتكلفة الإحالات التاريخية، وهذا التحديث لا يحتاج إعادة تنفيذها.
4. استخدم ملف `.env` الحالي الذي يخص هذا المشروع. النموذج الفارغ هو `.env.example`. لا تنقل متغيرات MongoDB أو توكن بوت آخر إليه.
5. نفذ:

```bash
npm ci
npm run typecheck
npm test
npm run build
npm start
```

يلزم Node.js 20 أو أحدث. يتحقق التشغيل من وجود ترقية قاعدة البيانات قبل بدء البوت. شغّل نسخة polling واحدة لكل توكن؛ عند نشر النسخة الجديدة أوقف نسخة polling السابقة أولًا.

للتثبيت الجديد استخدم `supabase/schema.sql` الكامل ثم املأ `.env` من النموذج. لا تحتاج تنفيذ migrations مرة أخرى بعد المخطط الكامل.

## لوحة التخصيص

افتح `/admin` ثم **Customize**، أو أرسل `/customize` من حساب الأدمن.

- المجلدات: البداية، المنتجات، الشراء والتسليم، الإيداع، الحساب، الإحالات والهدايا، الدعم، الإشعارات، المتجر والأداء، الأزرار الأخرى.
- اختر النص أو الزر، ثم العربية أو الإنجليزية أو الفيتنامية. أرسل النص، عاينه، ثم اضغط حفظ. الإلغاء لا يحفظ المسودة.
- الأزرار تدعم النص واللون والرمز العادي أو premium emoji. الرموز في جسم الرسالة لها محرر مستقل.
- خيار اختيار زر من الواجهة يفتح محرر الزر الذي تضغطه. أزرار الروابط المباشرة تجدها أيضًا في مجلد الأزرار الأخرى بعد عرض شاشتها.
- تعديل بيانات المنتج والمخزون والصور والشرح يستمر عبر قائمة المنتجات وأزرارها الحالية. إعدادات البوت والمتجر وAPI متاحة أيضًا من مجلد المتجر والأداء.
- يجب الاحتفاظ بمتغيرات مثل `{amount}` و`{minimum}` عند تعديل القالب؛ المحرر يرفض حذف المتغيرات المطلوبة.
- تعليمات كل وسيلة دفع موجودة في مجلد الإيداع ويمكن حفظ نسخة لكل لغة. النص العربي القديم العام لا يحل محل النص الإنجليزي تلقائيًا.

### تحديث قائمة تعديل المنتجات

من `/admin → Products` تظهر المنتجات مباشرة بأزرار تحمل أسماءها وإيموجياتها المحفوظة. إيموجي البريميوم يظهر داخل الزر نفسه؛ لا تحتاج إعادة ضبطه. تشمل القائمة المنتجات المخفية والنافدة أيضًا حتى تستطيع إدارتها، مع أزرار الصفحات.

اختر المنتج لفتح أزرار الاسم والسعر وأقسام المخزون والحسابات، النصوص، الإيموجي واللون، الأرباح والإحالات والأسعار الخاصة، شرح الاستخدام، نموذج التسليم، الترتيب والإظهار، والخيارات المتقدمة. بقيت خيارات التعديل السابقة ورابط المنتج والمشترون متاحة. لا تحتاج كتابة رقم المنتج أو أمر لاختياره؛ تُرسل القيمة الجديدة فقط عند تعديل حقل.

زر الرجوع أو `/cancel` يلغي الإدخال المعلق ويعود إلى المنتج وقسمه. الحفظ بعد إرسال نص أو مرفق يعرض رسالة جديدة من البوت بدل محاولة تعديل رسالة الأدمن. حذف المنتج له معاينة تأكيد. فتح القوائم لا يكتب على المخزون؛ احتساب العدد من مخزون الحسابات متاح بزر مستقل داخل قسم المخزون، كما تستمر المزامنة بعد إضافة أو حذف العناصر.

هذا التعديل الإضافي لا يحتاج ترقية قاعدة بيانات جديدة إذا كانت `0044` مطبقة من الحزمة السابقة.

## اللغة والإيداع

اختيار اللغة محفوظ في سجل المستخدم. لا يظهر طلب اللغة مع كل `/start` أو إعادة تشغيل. المستخدمون الموجودون يحتفظون باللغة المسجلة، ويمكن تغييرها من الإعدادات.

إيداعات USDT على الشبكات تطلب المبلغ أولًا، ثم تحجز مبلغًا دقيقًا خاصًا بالمستخدم والعنوان ووسيلة الدفع. يجب إرسال الرقم المعروض كاملًا، بما فيه المنازل العشرية. عروض LTC تحجز مبلغًا دقيقًا بالسـاتوشي وسعر تحويل ثابت. لا تُقبل معاملة مستخدم آخر لمجرد معرفة TXID.

الإيداعات الشبكية القديمة التي لا تحمل حجز مبلغ موثوق تذهب للمراجعة اليدوية بدل اعتمادها آليًا. الدفع المباشر ينشئ الطلب ويدير الفائض في المعاملة نفسها؛ إذا اختفى المنتج تُضاف القيمة المحققة كاملة إلى المحفظة. لا يُعاد خصم الطلب عند تكرار المعالجة.

## الإحالات والأرصدة

استُبدل في **مسار التنفيذ** احتساب غرامة على المحفظة بسعر الإحالة الحالي عند مغادرة عضو للقناة؛ الدالة القديمة نفسها ما زالت موجودة وتمنع فقط تثبيت الإحالة المعلقة. السجلات المثبتة والمشتريات والتحويلات القديمة لا يعاد تسعيرها.

الإحالة الجديدة تثبت مرة واحدة بعد مسار التحقق من الاشتراك. هذا المشروع لا يحتوي تحقق موقع أو CAPTCHA؛ لم يُضف تحقق موقع وهمي إليه. الإشعار يستخدم لغة المستفيد.

الترقية لا تغير الأرصدة التاريخية، ولا تصفر رصيدًا سالبًا قديمًا بلا دليل. إصلاح بيانات مالية قديمة يحتاج مقارنة سجل العمليات والمدفوعات؛ لم يتم الاتصال بقاعدة الإنتاج أو تعديل أرصدة العملاء أثناء هذا العمل.

## المزامنة واستهلاك الشبكة

أهم أسباب الحمل التي عولجت: تنزيل كتالوج المورد كاملًا لكل منتج مرتبط، وتنزيل إعدادات كبيرة أثناء تحديثات المستخدمين، وكتابة بيانات المخزون نفسها دون تغيير، وتكرار فحص الاشتراك، ومحاولات الدفع عبر كل التركيبات بين المضيفات والبروكسيات.

- قائمة المورد مشتركة خلال دورة المزامنة. بيانات المصادر والمنتجات المحلية تقرأ على دفعات، وتُكتب التغييرات فقط.
- إعدادات العرض وبيانات المنتجات الثابتة تستخدم رقم مراجعة صغيرًا. تغيّر المخزون يستعمل استجابة أصغر، بدل تنزيل الأوصاف والمرفقات كلها.
- تغييرات الكتالوج المحلية يراها العرض خلال 15 ثانية على الأكثر في العملية الأخرى؛ مسار الشراء يفحص الحالة الحالية داخل المعاملة.
- تغييرات المورد الخارجي تصل عند دورة المزامنة التالية. الافتراضي 10 دقائق، ويمكن ضبطه من مجلد المتجر والأداء، بحد أدنى دقيقة. زر المزامنة اليدوي الحالي يظل متاحًا.
- عند إخفاء المنتج يدويًا لا تعيده المزامنة إلى العرض. نفاد مخزون API يخفيه تلقائيًا. الرد الجزئي أو المتكرر لا يُعامل كدليل حذف بقية المنتجات.
- API يدعم ETag للكتالوج، ومحددات للطلبات، واستجابات JSON مضغوطة من حيث التنسيق. مفاتيح وأرصدة ومخزون المتاجر لا تشترك في ذاكرة التخزين المؤقت.
- Binance وBybit لهما محاولتان كحد أقصى في الجولة ووقت إجمالي محدود، مع تأجيل عند الحظر أو عدم توفر الخدمة.

من **Customize → قياس الطلبات والبيانات** تستطيع رؤية عدادات حسب الجهة ومصدر الطلب منذ بدء العملية. تقدير البايتات يعتمد على ترويسات HTTP، وقد ينقص عندما لا ترسل الخدمة Content-Length. هذه العدادات ليست فاتورة الاستضافة ولا إثباتًا لحجم شهري محدد.

## حدود التحقق

الاختبارات تستخدم قاعدة PostgreSQL محلية وبيانات حسابات ومدفوعات وهمية، ومعالجات البوت الفعلية مع بدائل HTTP. جرى اختبار مسارات اللغة والتخصيص والشراء والإيداع والصلاحيات والتخزين المؤقت. لا تمثل ذلك تجربة تحويل مالي حقيقي أو جلسة Telegram على هاتف فعلي، ولا تشغيل عدة خوادم إنتاج فعلية. حالات فشل شراء المورد الغامضة تبقى للمراجعة ولا يعاد شراؤها عشوائيًا. قد تعاد رسالة التسليم نفسها بعد انقطاع بين إرسال Telegram وحفظ اكتمالها، مع بقاء الخصم والمخزون محفوظين مرة واحدة.
